## Headings work like this

Regular paragraphs get comfortable measure and line height. **Bold** and _italic_
work as expected, as do [links](https://palios.io).

> Pull quotes get the color-block treatment — useful for the one line you want
> people to remember from an issue.

- Bullet lists are styled
- Including multiple items
- With tight spacing

1. Numbered lists too
2. In case an issue is a walkthrough

`Inline code` and code blocks are available if a signal happens to be technical:

```txt

```
